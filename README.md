# Six Star Clipper

Kostenlose Clip-Fabrik auf GitHub Actions für Content-Rewards-Kampagnen.

1. **Herunterladen:** genau den Ausschnitt (Start–Ende) aus YouTube-, Twitch- oder Kick-VODs (yt-dlp).
2. **Untertitel:** wortgenau auf Englisch (faster-whisper, läuft auf dem Runner).
3. **Rendern:** 1080×1920, Layout Split (Facecam oben, Spiel unten), Vollbild oder unscharfer Rand. Dazu Hook-Text (`*Wort*` wird gelb), Credit und Werbekennzeichnung `#ad`.
4. **Bereitstellen:** als öffentliche MP4 im Release `clips`. Diesen Link nutzt Claude für den Upload über vidIQ.

Kosten: 0 € (öffentliches Repo = unbegrenzte Actions-Minuten).

Nur Material aus Kampagnen verwenden, die das Clippen erlauben, und die Regeln der jeweiligen Kampagne beachten.
